## Licensing quarantine

The Claude integration repository contains draft code, content, and commercial licensing placeholders. They are useful requirements input but must not be replicated as binding terms until Charles identifies the owning Trust/LLC and qualified counsel reviews the strategy. The coordination hub's current CC0 license likewise needs explicit owner confirmation before valuable proprietary material is added.

## First round-trip test

1. Create one low-risk work item in this hub.
2. Send the same immutable ID and source hash to ChatGPT, Claude, and Gemini.
3. Collect each proposed output without overwriting the others.
4. Reconcile differences in a pull request.
5. Run validation and QA.
6. Obtain Charles's approval.
7. Stage the approved website or repository change.
8. Verify deployment and record the final artifact hash.
